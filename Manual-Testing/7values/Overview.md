# 7 Char  Values 💥
7 Char Values Application ([Link](https://testpages.eviltester.com/apps))

## Description 📝
This is a small web application with a single input field that validates a user’s input based on specific rules:

>The input must be exactly 7 characters long
>
>Only characters in the set A–Z, a–z, 0–9, and ‘*’ are valid
>
>When the value matches the rules, the app displays a success message; otherwise it displays an error.

This application deliberately contains bugs for testing practice and requires exploritory testing to find flaws.

## Prerequisites 🛠️
* A modern web browser (e.g., Chrome, Firefox, Edge)
* Internet access to reach the test page

## Goal 💡
Verify that the 7-Char-Val application correctly enforces the length and character set rules, handles invalid input gracefully, and correctly differentiates invalid and valid data.

## Feature Scope 💾
- Input Validation

## Key QA Concepts 🧠
- Exploritory
- Bountary Value Analysis
- Equivalence partitioning

## Conclusion 💬
The 7-Char-Val app is a focused test exercise designed to practice fundamental QA techniques, including boundary value analysis, exploratory testing, and validation logic verification. This project ensures that input validation rules are both implemented correctly and robust against unexpected user behavior, and that bugs are captured and converted into meaningful regression test cases.
